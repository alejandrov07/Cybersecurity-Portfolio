# Linux Package Management for Security Tool Deployment

## Overview
This report documents the installation, removal, and verification of essential network security tools on a Debian-based Linux system. As part of preparing a functional security analysis environment, package management operations were performed using the Advanced Package Tool (APT) to ensure that required applications were correctly deployed and operational.

The objective was to validate the ability to manage security tooling reliably at the operating system level, a foundational skill for incident response and network monitoring tasks.

Completed in March 2026 (exact day not recorded).

## Environment
- Operating System: Debian-based Linux
- Package Manager: APT (Advanced Package Tool)
- Shell: Bash
- Security Tools: Suricata
